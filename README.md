# Louise Ashley Ocampo · Portfolio

**Live site: [ashleyocampo.vercel.app](https://ashleyocampo.vercel.app)**

The personal site of an AI automation engineer and designer. It shows two kinds of work side by side: systems that take repetitive work off legal and business teams, and creative design for brands, campaigns and products.

The site is built to prove the work, not just describe it. Two of my tools run right on the page, and the design and motion were built with the same care as the engineering.

## What's on the page

- **Legal operations.** Four systems built for a U.S. collections law firm (bank statement reader, registered agent research agent, legal notice builder, PDF tools), presented as stacked folders. The code belongs to the client, so each folder explains the problem and the system instead of showing it.
- **Try it: packet-builder.** A working in-browser version of my open-source [packet-builder](https://github.com/ocampolouiseashley-jpg/packet-builder). Edit the customer list, change the page settings, turn double-sided printing on or off, and the print batch rebuilds live. Rows with missing data are skipped with a reason, exactly as the real tool does.
- **Business systems.** CRM, GoHighLevel, integration and AI-agent work, shown as an Apple-style feature switcher on a brushed-metal card.
- **Creative design.** A wall of real design work (posters, social campaigns, Amazon A+ content, UI) and four concept campaigns for fictional brands with AI-assisted art direction.
- **What I build with.** A 3D keyboard with one key per tool. Press a key to see where that tool was used in real work; the keyboard tilts toward the pointer.
- **How I approach problems.** A pinned scroll story: the section holds still while each step on a taped paper slip lights up in turn.

## How it's built

- Plain HTML, CSS and JavaScript. No framework and no build step, so it loads fast and is easy to maintain.
- Motion follows Apple's interface guidelines: scroll-linked scenes that track the scroll 1:1, a critically damped spring for the keyboard tilt, feedback on press, and a calm, still version for visitors who prefer reduced motion.
- Design direction and quality checks used a design review tool that measures the page in a real browser at desktop, tablet and phone widths (headline length, type sizes, contrast, overflow, covered text) before anything ships.
- Hosted on Vercel; every push to `main` deploys automatically.
